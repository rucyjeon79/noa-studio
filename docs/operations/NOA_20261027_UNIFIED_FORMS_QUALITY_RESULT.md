## 적용 내용

독립 등록·편집기, 통합 라이브러리, 음원·YouTube 목록의 수정창이 같은 필드 정의와 저장 API를 사용한다. 내 채널은 동일한 필드명·섹션 순서를 사용하되 본인 소유권과 공개·업로드 권한을 유지한다. 상단 4단 분류도 같은 분류 경로를 표시한다.

기본 정보 → 가사 → 제작 프롬프트 → 게시 정보 → 미디어 연결 → 해당 문서의 수록곡 → 추가 제작 자료 순서로 정리했다. 곡 소개와 YouTube 설명을 구분하며, 예전 필드 별칭은 수정 시 함께 맞춘다. 기존 비표준 보컬 값, 제작 자료, 원곡 정보와 변경 이력은 보존한다. 새 등록의 응답 확인이 실패한 경우에도 같은 요청을 다시 확인하여 중복 저장하지 않는다.

최고관리자 작업실의 콘텐츠 관리에 **곡정보 검사·정리**를 추가했다. 단일 전체 조회에서 저장 값 불일치, 원본 값 충돌, 제목 누락, 분류 확인 및 미디어 중복 후보를 보여준다. 값 확정은 검토 지문·문서 버전을 재검사하고 한 번만 저장한다. 원본 대안은 보존하고 해결된 충돌은 검사 결과에서 제외한다. 중복 후보 중 독립 기록은 기존 휴지통·복원 기능에 연결하며, 하나를 휴지통으로 옮겨도 남겨 둔 곡의 영상은 숨기지 않는다.

이전 음악 SQL 통합 화면은 **원본 가져오기·통합 등록**으로 구분했다. 일상적인 오류 수정은 검사·정리로 안내하고, 수집 당시 결과와 현재 해결되지 않은 원본 충돌을 구분한다.

## 사용법

1. 최고관리자로 [곡정보 검사·정리](https://noastudio.ai.kr/noa-quality.php)를 연다. 화면을 열면 전체 검사가 실행된다.
2. 저장 값·원본 값 충돌은 대안을 비교하고 **선택한 값 적용**을 누른다. 직접 입력하려면 **공통 곡정보 폼에서 수정**으로 이동한다.
3. 중복 후보는 곡정보를 비교한 뒤 불필요한 기록만 **휴지통으로 이동**한다. 조치 후 자동으로 재검사하며, 휴지통에서 복원할 수 있다.

같은 제목만으로 삭제하지 않는다. 동일한 원본에 여러 기록이 연결된 경우는 원본 연결을 검토한다. 원본 수집·DB·음원 처리·N80 도구는 각각 자료 가져오기, 서버 저장 상태, 음원 처리 재시도, 작업 보고 용도로 유지했다.

## 검증

- 320·390·1280px와 두 테마에서 독립/목록/내 채널 폼의 항목·라벨·순서, 상단 4단 분류, 가로 넘침을 확인했다.
- 격리 MySQL과 실제 PHP HTTP에서 신규 저장, 확인 응답 실패 후 재시도, 중복 EP·불완전 ACT 거절, 값 확정, 오래된 검토 거절, 이력·원본 보존, 휴지통·복원, 자동 재검사를 검증했다.
- Chromium/WebKit의 계정 이동 32개 경우와 공통 분류 4개 경우, 기존 기능 검사와 메타데이터 회귀 검사를 통과했다.
- 운영은 파일 40개의 SHA-256 일치, 변경 파일 18개, 보호 파일 23개 불변을 확인했다. 관리자 페이지의 비로그인 접근 차단, 공유 폼·검사 JS/CSS의 실제 응답 해시와 공개 홈도 확인했다.
- 이 배포의 운영 DB 쓰기·기존 회원 변경·포인트 차감은 0이다. 운영 곡의 올바른 대안을 임의로 선택하거나 중복을 자동 삭제하지 않았다.

전체 운영 회원의 인증 편집을 새로 완료했다고 주장하지 않는다. 별도 구형 실회원 검증은 이번 배포 이전에 회원 레벨 판정 기대값에서 실패했고, 관련 구형 시각 검사도 과거 메뉴·로그인 전 목록 가정을 포함한다. 상세 범위는 증거 JSON에 기록했다. 원래 12개 작업 영역과 N80 미완료 상태는 유지한다.

## 재개 후 실제 최고관리자 화면 확인

보안 로그인으로 최고관리자 자격을 확인하고 MY → 최고관리자 작업실 → 곡정보 검사·정리 경로를 실제로 열었다. 자동 전체 검사와 수동 재검사는 동일한 666개 곡·목록, 427개 검토 항목을 반환했다: 저장 값 불일치 409, 원본 값 충돌 13, 중복 후보 2, 제목 누락 0, 분류 확인 3.

중복 후보에서 곡정보 비교·수정과 휴지통 이동 버튼을 확인했다. 값 불일치에서는 원본별 값 비교, 선택 전 적용 비활성화와 선택 후 활성화를 확인하고 재검사로 임시 선택을 해제했다. 실제 곡의 독립 편집기와 검색 목록 수정창에서 공통 6개 섹션·항목명·순서와 상단 4단 분류가 일치했다. 내 채널 새 곡 폼도 같은 공통 항목·순서를 사용했다. 운영 곡 저장·삭제·복원은 실행하지 않았으며 해당 쓰기 동작의 검증 범위는 앞서 통과한 격리 MySQL/PHP 테스트다.

**427건은 아직 처리하지 않은 검토 항목이다.** 실제 427곡이 모두 잘못됐다는 뜻은 아니다. 확인한 카드 이미지 불일치 예는 현재 이미지 경로와 과거 빈 썸네일 값의 차이였다. 값을 남길 기준과 중복곡의 버전을 비교한 후 화면의 조치 기능으로 처리할 수 있다. 원본 회원 검증의 별도 실패 및 전체 N80 미완료 상태는 위와 같이 유지한다.
