# 플레이리스트 미리보기·로그아웃·추천곡 위치 수정

## 반영 내용

- 사용자 생성 사연곡·커버 플레이리스트도 저장된 공개 YouTube URL로 대표 카드 아래 미리보기를 연다. 우측 목록 버튼은 수록곡만 펼치며 플레이어를 다시 로드하지 않는다.
- 로그인한 회원의 공통 상단 바에 기존 그누보드 로그아웃 링크를 표시한다.
- 홈 추천곡의 기존 `/noa-youtube.php?track=…&play=1` 링크는 카테고리 → 장르 → ACT를 펼친 뒤 해당 EP로 이동한다. 선택된 곡을 표시하고 같은 자리에서 영상을 연다. 별도 페이지를 생성하거나 제목으로 모든 장르를 검색하지 않는다.
- 공통 테마 색상 적용만으로 목록을 다시 만들지 않아, 늦게 도착한 테마 설정이 선택된 EP나 영상 프레임을 초기화하지 않는다.
- 저장된 사용자 목록 순서를 받은 뒤 이동하므로 비동기 목록 로드가 현재 재생을 다시 시작하지 않는다. 사용자가 직접 선택하는 전체 영상·제목 검색은 유지한다.

## 원인

사용자 생성 플레이리스트가 공개 영상 카탈로그에서 제외되고 대표 카드가 수록곡 펼침만 처리했다. 공통 계정 바에는 로그아웃 링크가 누락돼 있었다. 추천곡 진입 코드는 곡 제목을 검색창에 입력하여 같은 제목의 다른 장르까지 결과에 표시했다.

## 범위

기존 네이티브 PHP 화면과 공통 탐색기를 수정했다. 기존 음악·회원·포인트 데이터, 인증 코어, 장르 및 EP 순서에는 쓰기 작업을 하지 않았다. 비공개·거절된 영상은 공개 재생 대상으로 승격하지 않는다. 저장된 URL이 없는 사용자 목록은 기존 펼침 동작을 유지한다.

## 검증의 범위

운영 SQL에서 투영한 공개 카탈로그 657개, 영상 원본 765개, 일반 영상 732개, 화면 행 876개를 사용했다. 운영 커버 목록 Vol.1~3의 공개 영상 연결과 사연곡의 동일 처리 경로를 확인했다. 운영 사연곡 사용자 목록은 없어 일회성 브라우저 시험 자료로 해당 경우를 검증했으며 DB에 저장하지 않았다.

브라우저 검증의 회원 정보와 YouTube 외부 전송 응답은 시험 자료다. 로그인 우회 없이 배포된 PHP 페이지 소스의 바이트 일치, 공개 자바스크립트·CSS, 실제 공개 데이터에 기반한 탐색과 영상 URL·플레이어 위치·펼침 유지·로그아웃 링크 동작을 검증했다. 실제 Google/YouTube 스트리밍 성공이나 실제 회원의 로그아웃 세션 종료를 이 증거로 주장하지 않는다.

홈·공지사항은 별도로 공개 브라우저에서 확인했다. 첫 이용안내 공지 게시 상태를 유지한다.

기존 통합 편집 검증의 비로그인 기대 경로가 `/bbs/login.php`로 고정되어 현재 `/noa-login.php` 전환을 실패로 판정했다. 공개 브라우저에서 실제 로그인 제한을 확인했고, 검증은 두 정상 로그인 경로·비밀번호 입력·원래 목적지 보존·편집/카탈로그 미노출을 모두 확인하도록 갱신했다. 인증 코드는 바꾸지 않았다.
