# 사연곡·커버 플레이리스트 미리보기 및 로그아웃

사용자 요청:

> act 플레이리스트는 유투브 미리보기 재생이 되는데 사연곡, 커버곡은 안돼
> 로그인 후 로그아웃이 없어

추가 확인: 문제 위치는 **사연곡·커버 플레이리스트**의 대표 카드다. 개별 곡이나 음원 화면이 아니다.

완료 기준:

- 저장된 YouTube 영상 URL이 있는 사용자 생성 사연곡·커버 플레이리스트도 ACT와 동일하게 대표 카드 바로 아래 플레이어를 연다.
- 오른쪽 목록 버튼은 수록곡만 펼치고 접으며, 이미 재생 중인 프레임을 재생성하지 않는다.
- URL 없는 목록은 기존 수록곡 펼침 동작을 유지한다. 비공개·차단·명시적으로 거절된 영상은 재생 가능으로 위장하지 않는다.
- 로그인한 사용자의 공통 상단 계정 바에 로그아웃 링크를 표시한다. 그누보드의 기존 로그아웃 경로를 사용한다.
- 320px·390px·1280px, 다크·밝은 테마에서 메뉴 겹침과 버튼 조작을 확인한다.
- 기존 곡·수록곡 순서·회원·포인트 데이터와 인증 코어를 수정하지 않는다.

추가 사용자 요청: 히어로 추천곡을 누르면 같은 제목의 다른 장르를 검색하지 말고, 해당 곡이 속한 기존 장르 → ACT → EP 순서와 위치를 따라가야 한다. 별도 페이지를 만들지 않는다.

- 기존 `/noa-youtube.php?track=…&play=1` 링크에서 해당 장르와 ACT를 펼치고 곡 위치로 이동한다.
- 전체 제목 검색 입력은 비우고, 같은 제목의 타 장르 곡은 함께 표시하지 않는다.
- ACT의 EP 순서, 저장된 커버·사연 목록 순서, 공개 여부와 기존 전체 검색 기능을 유지한다.
