# NOA-20261026-AI-AUTOMATION

## 사용자 원문

> n80 엔진에 자동화 구현하고.
>
> 사이트 떠다니는 AInoa에 최고관리자가 버튼 누르면 챗지피티와 연결된 대화창 연결.
> AI생성 기능구현 시작

## 구현 범위

- 최고관리자에게만 AInoa의 관리자 대화 버튼을 표시하고 모든 서버 요청에서 동일 권한을 검사한다.
- 관리자 대화·선택 곡 문맥·곡별 AI 생성 요청을 N80 SQL 작업으로 기록한다. 대기·처리·초안 검토·오류·응답 불확실·취소를 구분한다.
- 최초 요청 ID를 재사용하고 CAS로 단일 실행을 보장한다. 불확실한 응답은 자동 재과금하지 않는다.
- 서버 설정이 없으면 요청을 대기 보관한다. 설정 완료 후 기존 서명된 Actions 실행기가 텍스트 작업을 처리한다. 미디어 게시 실행기는 유지한다.
- 초안은 별도 보관한다. 기존 곡 정보는 기존 편집기의 명시적 검토·저장을 통해 변경한다.
- ChatGPT 구독 로그인·현재 ChatGPT 대화 기억·Work 내부 제어·코드 실행을 연결했다고 표시하지 않는다. 원격 호스팅 앱의 구독 사용은 별도 접근 승인·OAuth 등록이 필요하다.

## 검증과 완료 기준

격리 MySQL 실제 상태 전이, 네이티브 PHP 권한·CSRF·재조회, 모바일 360/390/430px 두 테마의 실제 배포 자산 검사를 요구한다. API 응답 fixture 검증은 실제 모델 생성 성공으로 계산하지 않는다. 실제 제공자 연결과 응답이 확인될 때까지 전체 상태는 미완료로 유지한다.
