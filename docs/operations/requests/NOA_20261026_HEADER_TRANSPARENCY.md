## 적용 기준

공통 고정 상단 바의 왼쪽에 기존 PAPA 심볼·홈으로·사이트맵을 배치한다. 오른쪽 로그인 또는 잔액·구독 상태·MY는 유지한다. 홈과 네이티브 게시판의 중복 상단 행은 제거하며 관리자 화면은 기존 구조를 보존한다.

세로 히어로 하단 배경은 투명도 90%(불투명도 10%)로 조정하고 배경 흐림을 제거한다. 영상 전체와 기존 가로 배치는 유지한다. 글자 그림자로 읽기 쉽게 처리한다.

이전 원문과 완료 증거는 보존한다. 연결 정보·원본 자료가 없는 항목이나 실제 기기 검수를 임의 완료로 처리하지 않는다.
