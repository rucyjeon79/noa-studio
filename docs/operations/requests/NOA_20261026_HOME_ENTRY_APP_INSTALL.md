# 홈 진입과 Apple 앱 설치 보완

요청: 첫 접속은 항상 인덱스 홈으로. Apple 설치 바로가기 누락을 해결하고 이어서 마무리한다.

기존 수정의 누락은 설치형 웹앱만 판단한 분기와 오래 남는 sessionStorage 플래그였다. 일반 브라우저의 과거 음원 주소 진입, 저장소를 쓸 수 없는 경우, 권한 안내 페이지에는 보정이 적용되지 않았다. 이번 변경은 같은 사이트에서 누른 링크와 곡·장르·게시판 앵커·OAuth 경로를 유지하면서 과거의 빈 음원 주소 및 해당 로그인 반환 주소로 직접 접속하면 홈으로 보낸다.

Apple 설치는 앱스토어 배포가 아닌 홈 화면 웹앱으로 제공한다. 공통 앱 설치 페이지와 상단·사이드바·사이트맵·MY의 바로가기를 추가한다. iPhone/iPad는 Safari 공유 → 홈 화면에 추가, Mac은 Safari Dock에 추가, Android/PC는 브라우저 설치를 안내한다. 홈에서 안내를 열면 설치 주소를 깨끗한 `/`로 정리한다. 기존 APK 링크를 Apple에서 열어도 설치 안내로 연결한다. 원본 Android 서명 및 APK 파일은 변경하지 않는다.

기존 manifest의 앱 identity는 유지하며 시작 주소 `/`는 보존한다. 브랜드 스크립트가 최신 manifest 링크를 과거 버전 주소로 덮어쓰던 동작도 수정한다. 권한 안내 화면에 최신 진입 보정 스크립트를 적용한다. 음악·회원·게시글 데이터는 변경하지 않는다.

검증: launch 조건별 단위 검사, 실제 native 접근 분기를 사용하는 격리 PHP fixture, Chromium/WebKit의 기기별 화면과 홈 안내 동작, 운영 익명 브라우저 진입 및 설치 페이지 검증. iOS 홈 화면 추가 OS 대화상자나 물리 iPhone 설치 완료를 자동화한 것으로 주장하지 않는다.
