# 2026-10-27 계정 메뉴와 곡 묶음 탐색

사용자 요청: 상단 계정 정보를 제거하고, 하단 MY 자리를 비로그인 시 로그인 아이콘/링크, 로그인 시 MY로 전환한다. MY 상단에는 현재 구독상태, 잔여 포인트 및 내역, 로그아웃을 배치한다. 상단 왼쪽은 심볼과 NOA STUDIO, 오른쪽은 홈으로/사이트맵/앱 설치를 유지한다.

음원과 영상의 공통 탐색은 카테고리 → 세부 장르 → 곡 묶음(미분류 포함) → 세부 목록으로 통일한다. ACT 바로보기 경로도 같은 구조를 사용하며, 저장된 ACT·EP·사용자 모음 순서 및 추천곡 위치 이동은 보존한다. 미분류는 펼침/접힘 카드로 제공하고 관리자 생성·순서 편집 진입 시 펼친다.

범위: 기존 UI 토큰, 실제 membership API 및 원래 로그인/로그아웃을 재사용하는 표시 변경. 회원 등급/권한, 회원 데이터, 구독·포인트 거래, 음악/영상 원본, 홈·공지·게시판 데이터는 변경하지 않는다. 검증용 회원은 격리된 PHP fixture에만 존재한다.
