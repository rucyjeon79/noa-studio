# 홈 커뮤니티 최신 소식 — 게시판별 제목 5개

요청: 공지 게시판을 제외하고 홈의 커뮤니티 최신소식에 각 게시판 최신글 5개씩 제목을 표시하며, 누르면 아래로 펼치는 기존 동작을 사용한다.

- 네이티브 게시판 목록에서 공지사항을 제외한 게시판을 순서대로 표시한다. 현재 자유게시판, 갤러리, 질문답변, 사연곡 신청이다.
- 홈은 각 게시판의 최신 제목을 최대 5개씩 표시한다. 글이 없으면 해당 게시판 아래에 등록된 글이 없다고 안내한다.
- 목록에는 제목만 포함한다. 본문·댓글은 펼칠 때 기존 회원 권한 확인 후 읽는다. 비회원은 펼친 영역의 로그인 안내로 이동하고 로그인 후 원래 글로 돌아올 수 있다.
- 사연곡 신청의 제목은 공개하고 본문은 기존 작성자 계정과 글 비밀번호 또는 최고관리자 권한을 확인한다. 일반 비밀글·그룹 전용·인증 전용·등급 제한 게시판은 기존 제한을 유지한다.
- 공지사항 대표 카드와 이전 글은 기존 독립 영역에 유지한다. 새 게시글이나 샘플 글을 운영 DB에 만들지 않는다.
- 기존의 접기 버튼과 따라오는 ‘펼친 내용 접기’ 동작을 공유한다. 한 글을 열면 앞서 펼친 글은 닫힌다.
