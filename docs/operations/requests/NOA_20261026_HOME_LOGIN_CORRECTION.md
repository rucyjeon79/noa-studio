## 적용 기준

기존 NOA 계정 아이디·비밀번호 폼을 처음부터 표시한다. 기존 계정의 이메일은 해당 NOA 계정을 찾는 데만 사용하며 네이티브 비밀번호 검증을 유지한다. Google·Kakao 계정의 비밀번호를 NOA로 받는 방식은 제공하지 않고 해당 서비스의 OAuth 인증을 사용한다. 직접 회원가입 버튼과 서버 직접 가입 경로는 막는다.

공지사항은 기존 notice 게시판을 읽으며 공개 글을 임의로 생성하지 않는다. 가장 최근 공개 글 1개를 대표 카드로, 다음 4개를 제목 행으로 보여 준다. 게시판의 열람 등급·그룹 제한·본인 확인 제한·비밀글을 우회하지 않는다.
