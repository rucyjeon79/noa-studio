## 동작

홈의 커뮤니티 최신 소식에서 공지사항을 제외한 자유게시판·갤러리·질문답변·사연곡 신청의 최신 제목을 게시판별 최대 5개 표시한다. 공지사항은 기존 독립 영역에 유지한다. 제목을 누르면 같은 자리 아래로 펼쳐지며 기존의 따라오는 접기 버튼을 사용한다. 다른 글을 열면 앞서 열린 글을 접는다.

제목 목록에는 본문이나 댓글을 포함하지 않는다. 비회원은 펼친 영역에서 로그인 안내를 받고 로그인 후 같은 글로 돌아온다. 회원의 읽기 권한, 그룹·인증 제한, 일반 비밀글 숨김을 유지한다. 사연곡 본문은 작성자 계정 및 글 비밀번호 또는 최고관리자 권한 확인 후 제공한다.

현재 운영 네 게시판의 글 수는 모두 0건이다. 각 게시판은 등록된 글이 없다고 안내하며, 이후 실제 글이 등록되면 최신 제목을 자동 표시한다. 운영 DB에 예시 글이나 테스트 회원을 생성하지 않았다.
