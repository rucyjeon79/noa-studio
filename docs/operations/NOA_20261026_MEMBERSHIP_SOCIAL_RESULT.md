- CSS/JS 주소에 실제 배포 파일 해시를 사용해 이전 스타일이 남는 문제를 줄였다.

## 회원 정책 적용 범위

- 신규 가입 경로는 Google·Kakao만 허용한다. 직접 가입 GET은 소셜 화면으로 이동하고, 직접 가입 POST·인증 세션 없는 소셜 가입 POST는 서버에서 거부한다. 기존 계정·관리자 로그인과 본인 정보 수정은 유지한다.
- 우측 상단에 로그인 또는 잔액·포인트 내역·구독 상태·남은 일수·MY를 표시한다. 별도 공간을 사용해 관리자 저장 버튼을 가리지 않는다.
- 일반 회원 2~4레벨은 잔액 1,000P 기준으로 2/3레벨을 조정한다. 유효한 VIP는 4레벨을 유지하며 5레벨 이상과 최고관리자는 보존한다.
- VIP는 3,000P를 차감해 정확히 30일 이용한다. 구매 동의와 자동연장 동의를 별도로 저장하고, 중복 주문·만료·잔액 부족·자동연장 해제를 처리한다.
- 로그인만 하면 0P다. 한국시간 하루 한 번 로그인 100P를 대기시키고 첫 글 50P 또는 댓글 30P 적립 때 함께 지급한다. 첫 댓글은 130P다. 기존 게시물/댓글 식별자를 사용해 중복 적립을 막는다.
- YouTube 시청 보상 비활성, 기존 접근 권한 등 현행 정책을 유지한다. 1P=1원 충전은 검증된 결제 영수증이 있어야 지급하며 미설정 상태에서는 신청을 막는다.
- 포인트·회원 테이블은 같은 운영 DB 안에서 백업·복원 검증 후 InnoDB로 이전했다. 회원 원문과 복호화 키를 외부로 내보내지 않았다.
- 기존 GnuBoard의 포인트 관계 ID 20자 제한에 맞춰 주문 참조를 저장하고, 전체 주문 ID는 100자 관계 동작 필드와 별도 주문 문서에 보존한다. 원래 게시물 관계 ID는 유지한다.

## 연결 대기와 기존 미완료 항목

- Google Client ID/Secret, Kakao REST API Key/Client Secret이 운영 설정에 없다. 가입 화면과 서버 제한은 반영됐지만 실제 신규 가입은 연결 준비 중이다. 기존 계정 로그인은 가능하다.
- 최고관리자 설정: `/adm/config_form.php#anc_cf_sns`. Google 콜백은 `https://noastudio.ai.kr/plugin/social/?hauth.done=google`, Kakao 콜백은 `https://noastudio.ai.kr/plugin/social/?hauth.done=kakao`다. 비밀값은 보고서나 공개 저장소에 넣지 않는다.
- AI 실제 응답은 앞선 보고서의 API 키·활성화·사용 한도 미설정 상태다. 현금 충전은 결제 수단·인증정보 설정과 실제 결제 검증이 남아 있다.
- N80 음악 가용성 오류는 복구했다. 회원 전용 음원에 검증기가 비회원으로 접근해 302가 나던 문제와, 저장된 가사·설명 수정값을 기대값에 반영하지 않던 문제를 수정했다. 검증 요청은 고정된 읽기 경로·메서드·Range만 HMAC으로 허용하며 게스트 권한은 유지한다. 과거 3회 실패한 작업 83은 원본 실패 상태를 같은 비공개 위치에 보존하고 실제 가용성 재확인 후 한 번의 재시도 주기를 허용했다. 세대 번호는 3에서 다음 claim의 4로 진행하며 성공 확인을 임의로 만들지 않았다.
