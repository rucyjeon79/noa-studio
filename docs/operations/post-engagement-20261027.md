# 게시물 좋아요·댓글과 인기점수

2026-10-27 사용자 요청: 게시물마다 좋아요와 댓글을 제공하고 두 반응을 인기점수에 반영한다.

## 적용 동작

- 공개 음악·영상·플레이리스트 카드와 공개 게시판 상세/홈 공지·커뮤니티 글에 반응을 제공한다. 같은 음악의 별칭은 같은 곡으로, 같은 영상의 여러 화면은 같은 영상으로 처리한다.
- 회원은 게시물별 좋아요를 한 번만 등록하거나 취소할 수 있다. 댓글 작성은 기존 정회원 및 게시판 등급 권한을 따른다. 작성자와 최고관리자만 새 댓글을 삭제할 수 있다.
- 음악 인기점수는 기존 공개 YouTube 조회수 + 유효 음악 재생수 + 좋아요 수 + 삭제되지 않은 댓글 수다. 각 반응은 1점이며 기존 시간별 순위 발행 주기를 유지한다. 같은 대상은 상위 목록·장르 집계에서 한 번만 더한다.
- 게시판에 표시하는 점수는 기존 조회수 + 기존/새 좋아요 합집합 + 공개 댓글 수다. 기존 게시판 추천 원본과 댓글은 보존하며 새 상태를 합쳐 표시한다.
- 취소·삭제는 이후 집계에 반영된다. 이미 발행한 과거 시간의 순위는 재작성하지 않는다.
- 비공개 사연, 비밀글, 별도 인증·그룹 접근 제한 게시물은 새 API에서 차단하고 기존 접근 절차를 유지한다.

## 보존 및 운영

회원·음원·원본 게시물·그누보드 코어는 변경하지 않는다. 반응 상태·이벤트·댓글용 InnoDB 테이블 세 개만 추가한다. 실제 댓글에는 기존 활동 포인트 정책을 적용하고 삭제 시 해당 관계의 지급 내역을 취소한다. 포인트 정책 자체는 바꾸지 않는다.

배포는 보호 대상 원본 해시를 검사하고 범위 내 파일 8개만 원자 교체한다. 설치용 인증 경로는 무작위 이름·만료 시간·비밀 헤더로 제한하고 작업 후 제거한다. 운영 검증에서는 테스트 회원·좋아요·댓글을 만들지 않는다.

## 검증

- 실제 MySQL: 추가 설치 재실행, 중복 좋아요, 댓글 저장 재시도, 본인 댓글 삭제, 과거 집계 시점 보존, 비공개·등급·그룹 접근 차단, 기존 추천 데이터 보존.
- 실제 HTTP API: 로그인·CSRF·Origin 검사, 저장·취소·삭제와 카운트 변경, 음악 별칭/영상 대상 확인.
- Chromium UI: 390px/1280px, 밝은/어두운 화면에서 댓글 저장·삭제, 가로 넘침 없음, 조작 영역 44px 이상. 생성된 화면 이미지를 직접 확인했다.
- 기존 인기점수 및 실음원 유효 재생 검사를 통과했다. 실음원 격리 사이트에 새 집계 의존 파일을 복사하도록 보완했다.

## 호스팅 응답 형식 보완

첫 배포 `40497288620`은 소스 8개 설치와 추가 테이블 생성에 성공했으나, 운영 호스팅의 HTTP 401 응답이 JSON 대신 Apache HTML 오류 문서인 것을 검사에서 허용하지 않아 소스를 자동 복구했다. 기존 회원 API 두 곳에서도 동일한 호스팅 동작을 확인했다. 테이블과 기존 데이터는 보존했다.

후속 PR https://github.com/rucyjeon79/noa-studio/pull/238 에서 운영 검증은 HTTP 401 차단을 필수로 유지하고 JSON인 경우 세부 오류도 검사하도록 보완했다. UI는 HTML 401에 로그인 안내를 표시한다. 브라우저 회귀 검사에 이 운영 응답 사례를 추가했다. 인증·권한·CSRF 요구 사항은 그대로 유지한다.
