## 검증과 운영 기록

- [홈·게시판 운영 검증](https://github.com/rucyjeon79/noa-studio/actions/runs/40329865590): 성공. 원래 설치 앱 시작 동작 5개, 격리 MySQL에서 작성자·타인·숫자 레벨 10·최고관리자 접근, 비밀번호·CSRF·댓글 권한·직접 게시판/예쁜 주소 차단·중복 등록을 검사했다. 게시판 브라우저 12개 화면과 실제 운영 홈 18개 화면을 통과했다.
- 운영 새 게시판 생성과 재실행을 검증했다. 기존 게시판·기존 글·회원 행·포인트는 수정하지 않았다. 활성화용 임시 도구는 제거했다.
- 기존 호스팅은 401 응답 본문을 Apache 오류 HTML로 바꾼다. 비로그인 검증은 실제 차단 상태를 확인하며 화면은 HTTP 401을 로그인 안내로 처리한다. 보호 본문 응답의 접근 검사는 격리 SQL/API 테스트에서 별도로 검증했다.
- [첫 공지 보완 게시](https://github.com/rucyjeon79/noa-studio/actions/runs/40331338679): 성공. 원래 게시글의 본문 SHA·작성자·표시값이 일치할 때만 갱신했고 같은 요청 재실행 시 추가 변경이 없음을 확인했다. 공지 수 1, 게시글 ID 1 유지. 모바일·PC 두 테마의 실제 공개 홈 4개 화면을 검증했다.
- [뮤비 작업실 최종 UI 검증·배포](https://github.com/rucyjeon79/noa-studio/actions/runs/40332228096): 성공. 함께 보관한 배포 영수증과 브라우저 보고서로 확인한다. PHP 저장·버전 충돌·키 암호화·중복 생성·출력 검증과 6개 화면에서 전체 제작·재열기·가져오기·내보내기를 확인한다. 운영 소스는 SHA로 확인하고 기존 홈·탐색·AI LAB 실행기·회원 관련 보호 파일 20개는 보존한다.

증거: [completion-20261026](completion-20261026/). `home-portrait-live.jpg`는 실제 비로그인 운영 화면이다. 게시판·뮤비 권한 및 생성 흐름은 격리된 인증/공급자 fixture를 사용했다. 운영 회원 로그인이나 실제 유료 AI 호출을 검증한 것으로 계산하지 않는다.
