# N80 사이트 직접 요청 뮤비 제작 — 2026-11-17

## 확정 요구

자동쇼츠·GitHub 예약 실행은 폐기 상태를 유지한다. 사용자가 사이트에서 **뮤비 제작 시작**을 누르면 별도 ChatGPT 창이나 복사·붙여넣기 없이 기획, 이미지 생성, 모션 영상 편집, 검수, 원곡 합성, N80 저장을 이어간다. 16:9는 전곡, 9:16은 직접 선택한 최대 59초다. 기존에 취소·정지한 작업은 자동 재개하지 않는다.

## 구현

- `bridge/movie-execution.php`: 기존 `agent_movie` 상태 저장소에 단일 명시 요청을 기록하고, 기존 계정 실행기의 고정된 `noa-movie.yml`만 호출한다. 중복 클릭은 재전송하지 않는다. 불명확한 전송은 자동 재시도하지 않는다.
- `bridge/movie-worker.php`: 기존 비공개 실행기 키와 관리자 소유자를 검증한다. 유효한 실행 ID에 연결된 해당 뮤비만 읽고 변경할 수 있다. 작업 목록 조회·다른 작업 접근·게시·일정 등록 권한을 주지 않는다.
- `lab/movie-worker.py`: 기존 ChatGPT 계정으로 Codex 0.166.0의 실제 이미지 도구를 사용한다. 별도 OpenAI API 키·Google 로그인은 사용하지 않는다. 공식 캐릭터시트를 실제 첨부하고 결과 파일을 검수한다.
- 이미지는 CLI의 실제 `CODEX_HOME/generated_images`에서 **이번 호출에 새로 생긴 파일만** 회수한다. 과거 이미지와 참조 이미지를 결과로 오인하지 않는다. 파일을 즉시 N80에 보관한 후 검수하므로 검수 중 오류 시 저장된 결과를 재검수할 수 있다.
- 채택한 이미지로 `session-motion.mjs`를 실행한다. 이는 이미지의 완만한 움직임이며, 인물 연기·립싱크 생성형 영상으로 표시하지 않는다.
- 기존 `session-assemble.mjs`의 장면 해시·프레임·길이·전곡/선택 구간 검증을 유지한다. 원곡과 최종 AAC를 실제 PCM으로 비교하고 상관계수 0.98 미만이면 저장 승인을 거부한다.
- 한글자막을 켠 요청은 실제 음성 인식으로 가사 시간을 분석한다. 불확실한 타이밍을 임의 확정하지 않고 검수 필요 상태에서 멈춘다.
- 계정 한도·캐릭터 불일치·불확실한 생성 결과·실행 시간 제한은 작업 카드에 사유를 기록한다. 정지·취소는 기존 lease를 해제하며, 재개는 새 명시 실행 ID를 발급한다. 호스팅에는 상주 프로세스를 추가하지 않는다.
- 개인 실행기 저장소의 작업 시간 제한은 120분이다. 계정 로그인 갱신 충돌을 피하도록 기존 텍스트 실행기와 동시 실행 그룹을 공유한다. cron은 없다.
- 생성 이미지 1장 확인용 임시 push 시험은 종료했다. 해당 검증 workflow는 명시 실행 전용으로 전환했다.
