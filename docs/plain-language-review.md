# 사용자 화면 용어 점검

2026-11-03. 운영 화면 소스(deploy)와 연결 코드(bridge)를 검색하고, 화면에 표시되는 문장·버튼·입력 제목·접근성 이름을 검토했다. 기계 처리용 JSON·SQL·API 명칭, 주소, 데이터 키, 가사·사용자 입력 내용은 변경 대상이 아니다.

## 적용 범위

곡 정보, AI 제작, 앱 설치, 채널 연결, 음악 자료 통합, 작업 현황, 업로드, 구독·크리에이터 오류 안내, 결제 설정, 자료 관리, 분류·인기순위 관리. 정확한 변경 목록과 횟수는 `scripts/noa_plain_language_manifest.json`에 보관한다.

| 기존 표현 | 사용자 표현 |
| --- | --- |
| 전체 정보 JSON 파일 다운로드 | 곡 정보 파일 저장 |
| SQL 대기열 | 처리 대기 목록 |
| 작업 스키마 주소 | 작업 연결 안내 파일 주소 |
| 실행 토큰 | 자동 작업 연결 키 |
| Google 콜백 | Google 로그인 후 돌아올 주소 |
| APK 다운로드 | 앱 설치 파일 받기 |
| 영상 메타데이터 | 영상 상세 정보 |
| SQL 조회 콘솔 | 직접 조회 · 조회 명령 입력 |

## 남겨야 하는 전문 표현

- 외부 서비스에서 실제로 선택·복사해야 하는 항목명: GPT 설정의 ‘API 키 → 사용자 지정’, Google의 Client ID·Client Secret 및 YouTube 서비스 이름. 쉬운 설명을 앞에 붙이고 공식 항목명은 함께 제공한다.
- 관리자 직접 조회 화면의 SQL 명령 예시 및 지원 범위. 실행 문법은 번역하지 않는다.
- 상세 진단 자료·정해진 파일 입력 형식·파일 확장자와 실제 주소. 원본을 임의 번역하면 가져오기나 문제 확인이 어려워지므로 유지한다.
- 사용자가 작성한 노래 제목·가사·제작 지시문·게시글은 수정하지 않는다.

문구 수정은 일반 사용자를 위한 안내 개선이며 전문 관리 기능을 새로 설계하거나 제거하는 작업이 아니다. 문구 배포 시 최신 운영 파일에 검토된 문자열만 적용하고 PHP·JavaScript 문법과 공개된 스크립트 내용을 검증한다.
