00. 작업 재개 및 절대 원칙
중단된 Work 작업은 GitHub·운영 서버·DB·로그의 마지막 검증 완료 지점에서 재개한다. 이미 완료한 일을 처음부터 반복하지 않는다. 목표는 Grok 모방이 아니라 모든 사용자 소유 자산과 기능의 완전 승계, 독립 운영, 디자인·성능·사용성의 실질적 개선이다. 기존 음악·회원·게시글·설정·이미지·영상 원본 삭제 및 무단 덮어쓰기 금지. 별도 프리뷰 사이트 없이 정식 사이트에 안전한 변경부터 적용한다. 위험 변경 전 백업과 복원 가능성 확인 및 위험 보고. Grok 삭제는 사용자의 최종 승인 전 금지.

01. Grok 원본과 신규 앱의 1:1 기능 감사
Grok 전체 메뉴, 숨겨진 기능, 설정, Suno URL 분석 Node 모듈, JUKEBOX, 세계관, 이미지·영상, AI, 관리자 기능과 신규 GitHub·서버 구현을 비교한다. 사용자가 제공한 세로 4장·가로 4장 스크린샷을 원본 UI 참고로 삼되 화면만으로 확인되지 않는 동작은 코드와 실제 테스트로 확인한다. 기능별 원본 위치·신규 구현 파일·배포 여부·테스트 결과·누락·개선사항 대조표를 작성한다. 확인 불가를 완료로 보고하지 않는다.

02. Grok 자산 전수 이전
곡·가사·EP·ACT·장르·언어·버전·Suno/오디오/YouTube/MV URL·썸네일·NOA/NOEL 캐릭터시트·메인 움직이는 이미지·히어로·앨범아트·플레이리스트/세계관 이미지·로고·심볼·아이콘·MV·립싱크·홍보 영상·레이아웃·테마·다국어·JSON·SQL·백업·Node/API 소스·설정·작업 이력을 전수 조사한다. 자산별 ID, 원본 위치, 사용처, 파일 크기·형식·체크섬, 독립 저장 여부 기록. URL만 확보한 것과 원본 파일 확보를 구분한다. 권한 허용된 원본을 NOA 독립 저장소로 이전한다. 캐릭터시트 없는 임의 이미지 생성 금지.

03. 메인·심볼
기존 Grok 모바일 세로 메인에 쓰인 움직이는 이미지를 홈 히어로로 사용한다. 자동재생·반복·음소거·인라인 재생, 차단 시 원본 정지 이미지 대체. 별도 생성 이미지로 대체 금지. 아래 콘텐츠 박스와 폭·정렬을 맞춘다. 기존 공식 심볼을 웹 헤더, favicon, PWA, Android 런처·적응형 아이콘, 스플래시에 통일하고 캐시 갱신·설치 후 확인한다.

04. 화면·반응형·디자인
모바일 세로 우선, 태블릿 가로 우선, PC 가로 우선이며 모든 방향 지원. PC 창을 좁히면 뷰포트 기준 모바일 세로 레이아웃으로 전환. 화면은 충분히 활용하되 콘텐츠 과도 확대 금지. 320·360·390·430·768·1024·1280·1920px 검사. 겹침·어긋남·불규칙 줄간격·과다 밑줄·가로 넘침·카드 붕괴·하단바 충돌·팝업 잘림을 공통 컴포넌트 수준에서 수정. 컬렉션 카드는 기존 이미지 전체를 배경으로 채우고 하단 그라데이션 위에 제목·필수 정보만 표시. 블랙·골드 과용을 줄이고 고급 음악 매거진처럼 정돈한다.

05. 메뉴와 탐색
최종 순서: 홈 / YouTube / 세계관 / 음원 / MY. AI LAB과 관리자 기능은 별도 권한 영역. 홈=발견, YouTube=영상, 세계관=소설·공식 MV, 음원=Suno 고음질, MY=즐겨찾기·최근 재생·내 보관함·테마·언어·계정. 현재 위치, 돌아가기, ACT/플레이리스트 빠른 전환, 검색·재생 상태 유지. 메뉴 이동 단계를 줄인다. 정식 명칭은 '당신의 이야기, 우리의 음악 🎧', '🎤 AInoa의 유명곡 커버'; '사연곡/커버곡'은 내부 별칭이며 YouTube 매칭 시 원본 ID·정식명칭·별칭을 함께 활용한다.

06. 홈 정확한 섹션 순서
(1) 움직이는 히어로 자동재생 (2) 추천 음악: 공식 YouTube 롱폼 중 Shorts 제외 조회수 Top10 (3) EP 시리즈: 각 장르 조회수 1위 하나씩 (4) 당신의 이야기, 우리의 음악 🎧 Top10 (5) 🎤 AInoa의 유명곡 커버 Top10 (6) 플레이리스트: YouTube '연속듣기' 소속 조회수 Top10; 기존 홈 'ACT 플레이리스트' 명칭을 '플레이리스트'로 변경 (7) NOA 세계관 (8) 음악 컬렉션 (9) 커뮤니티 최신 소식. 순서 변경 금지. 조회수와 동기화 시각 표시, 실제 데이터 없는 순위 조작 금지. 재생목록 자체와 영상 조회수를 혼동하지 않는다.

07. 장르 페이지·ACT·플레이리스트
YouTube·음원 페이지 상단에 ORIGINAL / COLLECTION / OTHER GENRE 및 각 실제 장르를 모두 정돈하여 표시. 기존 4대 대분류(오리지널·EP·사연곡·커버곡)와 세부 장르 관계 보존. 장르 선택 시 장르 소개 상단 표시. ACT → 플레이리스트 순으로 정렬하고 선택 시 아코디언으로 수록곡 펼침. 컬렉션 카드는 기존 Grok 자산 및 YouTube 재생목록 이미지 우선 활용. 재생목록에 독립 대표 이미지가 없으면 확인된 소속 영상 썸네일 활용. 빈 ACT·플레이리스트는 원본과 SQL 연결을 재검증.

08. YouTube 영상
큰 16:9 실제 영상 썸네일, 제목, EP/ACT. 선택하면 NOA STUDIO 내부 공식 YouTube 플레이어로 즉시 재생. 큰 화면 아이콘은 공식 전체화면/YouTube 보기 동작으로 연결. 구독 안내는 제공하되 구독 여부를 검증할 수 없으면 비구독자라고 단정 금지. 외부 YouTube 재생목록 링크 버튼은 제거하고 내부 목록·순서는 유지. 공개 영상에 COMING SOON 표시 금지; 이 이미지는 기존 비공개/공개 예정 용도에만 사용. 비공개 권한 준수.

09. Suno 카드·원본 분석 모듈·JUKEBOX
Grok의 Suno URL 분석 모듈과 입력·출력·저장·재생 경로를 먼저 확인한다. URL로 곡 식별·제목·1:1 커버·가사/오디오 메타데이터를 기존에 어떻게 얻었는지 실제 코드로 확인한다. 독립 재구현이 당장 어렵다면 허용된 Grok Node/API를 임시 활용하되 최종 독립화를 추진. Grok 화면 노출 금지. Suno는 작은 1:1 커버(모바일 약 52~60px)+곡명+단곡 재생 버튼. 재생 버튼은 해당 한 곡만 재생. 담기 버튼은 JUKEBOX 큐에 추가; 한 곡, ACT/플레이리스트 전체, 장르 전체 담기 지원. JUKEBOX 재생 시 Suno 커버를 원형으로 표시. 공유 URL과 실제 재생 가능한 음원 주소 구분.

10. 음원 품질·다운로드
최적화 파일 없는 곡의 첫 재생 요청에서 원본 확보·분석·작업 대기·보정·저장 상태를 명확히 처리한다. 포맷·비트레이트·샘플레이트·LUFS·True Peak·클리핑·다이내믹을 측정해 기록. 요구 처리: 3단계 보정, 기존 Grok 정의를 확인한 Mastering Intensity 50, -14 LUFS 목표 정규화, -1 dBTP 피크 제한, 전후 측정값 기록. 원본 손상·왜곡 시 강제 처리하지 않고 예외를 기록. 최적화 MP3를 서버에 캐시하여 이후 재생과 관리자 MP3 다운로드에 재사용. 없으면 생성·저장 후 다운로드. WAV는 저장된 보정값과 최선의 원본을 이용해 요청 시 생성하고 임시 파일을 정리하며 서버에 영구 보관하지 않는다. 손실 음원 WAV 변환이 원본 이상의 품질을 복원하지 않음을 명시. 동시 작업·실패 복구·용량·권한 검증. JUKEBOX 원형 계기판은 12시 기준 좌측 빨강=마스터링 LUFS 변화, 우측 파랑=-14 LUFS 조정, 우측 노랑 겹침=피크 변화. 서로 다른 단위를 분리해 범례·값·눈금 명시.

11. 음악 데이터 및 미등록 곡
Grok 수집 JSON·SQL·임시 병합·대기 자료·ACT·플레이리스트·공식 YouTube 채널(@ainoa_ramjunpapa)을 전수 대조. 수집된 데이터가 실제 곡 레코드로 생성·연결·노출됐는지 확인. 제목/가사/Suno/YouTube URL 일부만 있어도 실제 기존 곡으로 식별되면 정보 보완 필요 상태로 등록. 없는 가사·음원·URL 임의 생성 금지. 기존 ID·Suno ID·YouTube ID·EP·언어·버전으로 중복 확인; 제목만으로 병합 금지. 수록 순서와 다중 소속 보존. 원본 곡 수, 등록 곡 수, 미등록, 충돌, 누락, 보완 수를 실제 숫자로 보고.

19. 최종 실행 명령
원본 조사 없이 임의로 화면·이미지·기능을 대체하지 말 것. 기존 Grok을 흉내 내는 수준이 아니라 원본 기능을 완전히 승계하고 NOA STUDIO 자체 운영 품질을 높일 것. 현재 중단된 Work를 마지막 완료 지점부터 재개하고, 안전한 변경은 정식 사이트에 적용하며 실제 결과를 증명할 것. Grok 앱은 사용자가 최종 승인하기 전까지 유지할 것.
