# 최고관리자 데이터베이스 관리

관리자 URL: `https://noastudio.ai.kr/noa-app/database/`

NOA 앱의 독립 모듈이며 루트 index.php와 그누보드 코어를 변경하지 않는다. 그누보드 최고관리자 세션, `cf_admin` 일치, POST CSRF 토큰을 모두 확인한다. DB 연결에는 서버의 기존 G5_MYSQL_* 설정만 사용한다. API 응답과 화면에는 DB 계정·비밀번호를 포함하지 않는다. 개인 캐시와 iframe 사용을 차단한다.

## 조회

연결 상태, MySQL 버전, 읽기 전용 세션 설정, 테이블·컬럼 목록, 음악·회원·설정 건수를 제공한다. 테이블 메타데이터의 행 수는 추정치이며 현황 건수는 실제 COUNT 결과다.

SQL 콘솔은 단일 기본 테이블 SELECT 문법을 파싱해 새 SQL과 바인딩 값으로 재구성한다. 임의 입력을 그대로 실행하지 않는다. 지원: 컬럼 선택, DISTINCT, WHERE 비교·LIKE·IS NULL·AND/OR, GROUP BY, ORDER BY, COUNT/SUM/AVG/MIN/MAX, LIMIT/OFFSET. JOIN·서브쿼리·CTE·주석·세미콜론·스키마 지정·변수·임의 함수·잠금·파일 출력은 허용하지 않는다. 결과는 최대 1,000행/4MiB이며 MySQL 실행 제한은 3초다. CSV는 같은 제한과 검증을 사용하고 스프레드시트 수식 시작 문자를 이스케이프한다.

## 백업

SQL·SHA-256 매니페스트·월별 실행 기록은 웹 루트의 형제 폴더 `noa-db-private`에 보관한다. 폴더 0700, 파일 0600이며 인증된 POST 다운로드에서 무결성을 재확인한다. 공개 URL로 백업을 제공하지 않는다.

- InnoDB: REPEATABLE READ의 일관된 읽기 스냅샷.
- MyISAM 포함: 선택한 테이블의 READ LOCK. 백업 동안 해당 테이블의 쓰기가 최대 40초 지연될 수 있다.
- 전체/테이블별 백업: 구조, 데이터, 생성 컬럼 제외 후 복원 시 재계산, 바이너리·JSON·NULL·UTF-8을 보존한다. 덤프 내부의 외래키 검사를 일시 중지한다.
- 안전 상한: 256MiB / 40초. 실패한 임시 덤프는 제거한다.
- 뷰·트리거·프로시저·함수·이벤트 또는 InnoDB/MyISAM 외 엔진이 있으면 실패 처리한다. 해당 경우 객체와 권한까지 보존하는 별도 전문 덤프가 필요하며, 불완전한 덤프를 전체 백업으로 표시하지 않는다.
- SHA-256 일치와 실제 복원 성공을 구분한다. 운영 백업은 별도 검증 DB에서 실제 복원하기 전까지 `restoreVerified=false`다.

## 승인된 복원

일반 SQL 화면과 웹 API에는 데이터 변경·복원 실행 동작이 없다. 복원 영향 확인은 대상 테이블·현재 구조와 행 수·백업 해시를 포함하는 1시간 유효 승인 계획만 생성한다.

1. 격리된 MySQL DB에 해당 운영 백업을 실제 복원하고 구조·내용을 대조한다.
2. 서비스의 쓰기를 중단하고 대상·영향 범위·복구 백업·해시를 최고관리자가 검토한다.
3. 운영 담당자가 서버 CLI에서 계획 ID, 검토한 SHA-256, 최고관리자 ID, 유지보수 확인을 명시한다.
4. 실행기는 계획과 백업 재검증, 현재 구조·행 수 변경 감지, 최신 전체 복구용 백업, 실행 기록 저장을 완료한 후 mysql 클라이언트에만 덤프를 전달한다. 비밀번호는 일시적인 0600 서버 설정 파일에만 저장하고 정상/실패 모두 제거한다.
5. 결과 행 수를 확인한다. DDL 복원은 원자적 롤백을 보장하지 않으므로 실패 시 유지보수 상태를 유지하고 기록된 복구용 백업으로 복구한다.

실행 예:

```sh
php /hosting/noastudio/html/noa-app/database/restore-cli.php \
  --plan=검토한계획ID --approve-sha256=검토한계획해시 \
  --actor=최고관리자ID --maintenance-confirmed
```

운영 배포 작업은 실제 복원을 실행하지 않는다. 구조·내용 변경에 대한 별도 승인을 유지한다.

## 검증

`tests/database/grammar.php`: 정상/악성 SQL 문법 40건.
`tests/database/mysql.php`: MySQL8 읽기 전용 세션, 상한, 유니코드, 집계, 전체·테이블 덤프, 독립 DB 실제 복원, 생성 컬럼·JSON·바이너리·NULL, MyISAM, 미지원 객체 거부, 변조 탐지, 회원 보존.
`tests/database/browser.mjs`: 일반/최고관리자 접근, CSRF 누락·오류, 쓰기·임의 함수 차단, 320/390/1280px 표시와 조회·구조·백업·복원 계획.

배포는 이 모듈과 `extend/noa.database.php`만 추가하고 index.php·기존 인증 파일·DB 설정의 해시를 대조한다. 기존 버전이 알 수 없는 경우 덮어쓰지 않는다.
