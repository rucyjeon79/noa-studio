# 7. 구현 순서

| 단계 | 내용 | 현재 |
|---|---|---|
| 1 분석 | 기능, 저장, 승계 | 이 문서. 운영 데이터는 변경하지 않음 |
| 2 설계 | 스키마와 매핑 | SQL 파일만 추가. DB 미실행 |
| 3 API | 조회와 부분 저장 | PHP 소스만 추가. 문법 실행과 닷홈 배포는 미검증 |
| 4 PC 테마 | 장르·곡 목록 | 껍데기만. 편집·재생·설정 화면은 없음 |
| 5 모바일 연결 | Grok 앱이 닷홈 API를 사용 | 시작하지 않음. 지금 바꾸면 저장이 끊긴다 |
| 6 배포 | 수동 FTP | 워크플로 파일만. 비밀값 미등록, 실행 안 함 |
| 7 이관 | 시험 테이블 후 전체 | 시작하지 않음. 사용자 승인 전 금지 |
| 8 통합 테스트 | PC와 모바일 왕복 저장 | 미검증 |
| 9 운영 전환 | 도메인과 쓰기 경로 | 승인 전 금지 |

다음에 실제 서버에서 할 일:

1. GitHub Secrets 세 가지를 등록한다.
2. FTP 시작 폴더를 확인한 뒤 수동 배포로 테마와 API만 올린다.
3. 그누보드에서 테마를 선택한다. 목록이 비어 있으면 이관 전 상태다.
4. 시험용 MySQL 테이블에 EP 하나를 넣고 저장, 새로고침, 충돌을 확인한다.
5. 그 테스트가 통과한 뒤에만 전체 이관과 모바일 연결을 승인한다.
