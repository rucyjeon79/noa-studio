# 4. PC 그누보드 테마 설계

모바일 앱을 PHP로 베끼지 않는다. 그누보드 테마는 `deploy/noastudio/theme/noastudio/`에만 둔다. 배포해도 관리자가 테마를 고르기 전에는 적용되지 않는다.

방향: 검은 배경, 골드 선, 기존 NOA·NOEL 사진. 새 인물 이미지는 만들지 않는다.

| 화면 | 이번 소스 | 아직 없음 |
|---|---|---|
| 메인, 장르 수, 곡 목록 | 테마 `index.php` | 이관 전이라 목록은 비어 있는 것이 정상 |
| EP·ACT 상세 | API의 곡 조회 | 편집 화면 |
| 플레이어 | 모바일 유지 | PC 재생기는 만들지 않음 |
| 관리자 편집, 설정, 이력 | API가 저장 규칙을 가짐 | PC 입력 화면 |

테마는 `/noa-api/index.php`만 호출한다. 로컬 JSON이나 샘플 곡을 넣지 않는다. API가 비어 있으면 "아직 이관된 곡이 없습니다"라고 표시한다.

그누보드 `head.php`와 핵심 파일은 테마가 대체하지 않는다.
