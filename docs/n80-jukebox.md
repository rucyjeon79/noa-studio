# N80 JukeBox

N80 Engine의 `jukebox` 전문 모듈이다. 별도 엔진, 작업 큐 또는 예약 실행자를 만들지 않는다.

- 등록부: `noa-app/engine/jukebox.php` → `registry.php`.
- `player.js`: 기존 인증된 곡 데이터, 단일 audio, 재생 의도, 다음/이전 곡, ACT/개인/추천 대기열, 반복/셔플, 볼륨, 위치 저장과 복원.
- `presentation.js`: 기존 플레이어 UI, 같은 문서를 유지하는 내부 페이지 이동, OS 미디어 제어, 영상/미리듣기와의 재생 충돌 조정.
- `navigation-policy.js`: 페이지 이동과 새로고침 복원에 사용하는 단일 정책. 인증·결제·다운로드·외부 주소는 기존 경로를 사용한다.
- 기존 업로드·음질 최적화·stream/download·재생 집계·개인 목록 저장소는 그대로 연결한다.

`window.N80JukeBox`가 유일한 재생 API다. `NoaMusic`은 같은 객체의 호환 이름이다. 설치된 Android 브리지가 사용하는 전역 접근자는 모듈 내부 상태만 참조하며 별도 상태를 만들지 않는다. Android 브리지가 있으면 브라우저 복구 실행자를 붙이지 않는다.

추천 화면과 내 재생목록은 곡 키로 공통 API를 호출한다. API는 인증된 현재 목록에 없는 키를 재생하지 않는다. 곡 수정·상세 조회·메뉴 이동은 audio를 교체하지 않는다. 재실행 시 기존 모듈을 반환하며 종료·일시정지 이후 자동 복구하지 않는다.

기존 `noa-navigation-player.yml`이 이 모듈의 통합 검증과 배포를 소유한다. `[n80-jukebox]` 변경에서는 겹치는 배포 작업을 실행하지 않는다. 알려진 서버 버전 검사, 후보 커밋 확인, 파일 해시 대조와 실패 시 원복을 유지한다.

검증 범위: 실제 브라우저 음원 재생과 페이지 이동(360/390/768/1280), 중복 초기화·종료·목록·재생 집계 회귀, 기존 Android 브리지와 실제 새 모듈의 결합, 운영 소스 대조. 실제 Android 기기의 화면 잠금/배터리 절약 정책 검증과 APK 재배포는 포함하지 않는다.
