# N80 수동 제작 전환 — 2026-11-17

사용자 확정: 자동쇼츠와 GitHub 예약 실행은 폐기한다. ChatGPT가 이미지·영상·뮤직비디오 제작을 직접 지휘한다. 16:9는 원곡 전체, 9:16은 기본 0~59초에서 사용할 구간을 직접 선택한다.

## 반영된 동작

- 제작 화면: https://noastudio.ai.kr/noa-ai-lab.php?tool=create
- 16:9 요청은 선택 구간을 받지 않으며 원곡 전체 길이로 계획·편집한다.
- 9:16은 시작·종료 초를 바로 입력한다. 기본값은 0~59초이며, 짧은 곡은 실제 곡 길이까지다. 길이는 0초 초과~59초 이하, 원곡 범위 이내여야 한다. 이전 49초 최소 제한을 제거했다.
- 선택 구간 미리듣기, 기본 구간 복원, 원곡 길이에 따른 장면 계획을 제공한다.
- ChatGPT가 현재 원곡과 제작 지침을 읽고 기획·이미지 생성·영상 편집·검수·저장을 진행한다. N80이 작업 ID, 원곡 버전, 파일, 검수와 재개 상태를 소유한다.
- `lab/session-motion.mjs`는 검수한 이미지에 완만한 줌을 적용하는 로컬 영상 도구다. 이미지 해시, 실제 인코딩·전체 디코딩, 해상도, 길이를 확인하고 `method=image_motion`, `generativeVideo=false`를 기록한다. 사람의 연기·립싱크를 새로 생성하는 도구로 표시하지 않는다.
- 원곡 합성은 기존 `lab/session-assemble.mjs`가 담당한다. 원곡·영상 해시, 실제 해상도·길이, 오디오와 결과 파일 검증을 유지한다.

## 자동 실행 폐기

- `.github/workflows/noa-ai-worker.yml`을 삭제했다. 승인된 예약 목록은 비어 있고, 예약 재등록 방지 검사도 유지한다.
- 예약 수신기는 HTTP 410 및 `scheduled_wake_retired`를 반환한다. 이전 활성화 플래그로 다시 켜지지 않는다.
- 자동쇼츠 작업과 readiness는 `retired`, `executionAllowed=false`, 다음 예약은 null이다. 이전 기록과 제작물은 보존한다.
- 자동쇼츠 메뉴·재활성화 경로를 제거했다. 기존 채널 자동 게시도 껐고 서버에서 재활성화 요청을 거부한다.
- 별개 수동 처리와 소스 검사·빌드용 GitHub 기능은 유지한다. 새 예약이나 상주 실행기를 추가하지 않는다.
