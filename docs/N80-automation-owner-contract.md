# N80 자동화·ChatGPT 협업 운영 원칙

사용자 승인: 2026-11-16. 이 문서는 운영 설계의 기준이며, 특정 기능이 이미 실행 가능하다는 증빙은 아니다.

## 1. N80은 사용자 작업의 주도적 실행자

- 새로운 작업 시작에는 **사용자의 명시적 액션** 또는 **개별 승인된 예약 시간**이 필요하다.
- 시작된 작업 안에서는 N80이 필요한 후속 단계를 스스로 처리한다. 모든 단계는 최초 요청 범위·작업 ID·원본 리비전으로 묶는다.
- 사용자의 지시 없이 AI 생성, 음원 정리, 점검, 알림, 게시, 수정 등의 **새 작업을 만들지 않는다**.
- 불분명한 완료 영수증은 성공도 실패도 아닌 `unconfirmed`로 보존한다. 무작정 재실행하지 않는다.
- 중복 실행 방지는 idempotency key, owner lease, 원자적 인수 및 완료 증빙을 기준으로 한다.

## 2. N80 ↔ ChatGPT 협업

- N80이 처리할 수 있는 작업은 직접 수행한다.
- 작업 중 ChatGPT 판단·업그레이드가 필요한 경우, 기존 N80 작업 상태를 `needs_chatgpt_upgrade` 또는 동등한 **기록 가능한 대기 상태**로 전환한다.
- 요청에는 작업 ID, 사용자 지시와 허용 범위, 현재 단계, 방해 원인, 원본 및 소스 리비전, 원하는 결과물과 검수 기준을 포함한다.
- ChatGPT가 실제로 연결되지 않은 상태에서 실행됐다고 주장하지 않는다. 연결 전에는 요청을 안전하게 보존한다.
- 재개는 인증된 사용자 요청 또는 이미 승인된 작업의 유효한 계속 실행에서만 허용한다.

## 3. 예약 작업은 GitHub를 통해 N80만 깨운다

- 승인 목록: `config/n80-approved-schedules.json`. 승인된 예약이 없으면 정기 실행도 없다.
- GitHub는 정해진 시각에 **서명된 단발 wake** 신호만 전송한다. GitHub가 직접 음악·영상·DB·큐·정리 작업을 수행하지 않는다.
- 실제 N80 작업은 호스트의 **검증된 경량 접수 경로**에서 승인/작업 ID/중복 방지/예산을 검사한다.
- 이 경로가 미구현·미승인·중지 상태면 GitHub는 실패를 기록하고 N80 작업을 시작하지 않는다.
- 닷홈에는 상주 Node 실행기, 10초 폴링, 무한 재시도, 예약 작업을 두지 않는다.
- 품질 테스트는 코드 변경/명시적 검수 요청에 반응할 수 있으나, 정기 무인 점검을 임의로 등록하지 않는다.

## 4. 호스트 저장 용량과 정리

- 호스트에는 사이트 실행에 필요한 최소 코드와 활성 업무 데이터만 남긴다.
- 백업은 Google Drive로. 업로드 ID, 해시, 크기, 다운로드/재검증 결과를 확인한 **다음** 정리를 시행한다.
- 원곡/완성음원/가사/미확정 창작 초안/회원/결제/연결 키/현재 작업 잠금/미확정 영수증은 청소 대상이 아니다.
- 불필요한 파일로 확인되어도 실제 참조 여부와 복구 가능성을 먼저 검증한다. 불분명하면 보존한다.
- 변경 전/후 백업과 작업 영수증은 호스트가 아닌 Drive 중심으로 관리한다. 호스트에는 필요한 작은 참조만 남긴다.

## 5. 배포·검수 조건

1. 기존 운영 상태와 파일 해시를 읽고, 바뀐 파일만 한정한다.
2. 코드 문법·검수·중복 실행/중지 상태 검사를 통과한다.
3. Drive 원본 백업을 만들고 실제 존재와 해시를 검증한다.
4. 운영 반영 후 실수행/재조회 증빙을 구분한다. 시뮬레이션 통과를 운영 성공으로 표시하지 않는다.
5. 승인 없는 예약, 자동 재실행, 호스트 데몬, 사용자 데이터 삭제, 미확정 작업 재생성은 회귀 검사에서 차단한다.

## 6. 현재 주의점

- 과거 N80 Hub의 상주 실행은 정지돼 있으며, 예약 wake 기능은 별도 인증·승인 E2E 전까지 미가동일 수 있다.
- 기존 사용자 업로드에서 GitHub 작업을 직접 수행하는 호환 경로는 signed N80 wake-only 방식으로 교체·실증되기 전까지 **개선 대상으로 표시**한다. 기능 보존을 위해 임의로 삭제하지 않는다.
- 물리적 파일 삭제는 별도 접근과 삭제 전 백업 검증이 필요하며 정책 추가만으로 삭제가 이루어진 것은 아니다.
