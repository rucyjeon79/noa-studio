# NOA STUDIO 가입약관·개인정보처리방침 초안

작성일: 2026-10-27. **작성 완료 / 운영 사이트 미게시 / 법률 적합성 확정 아님.**

사용자 요청: “구글 수정 완료. 가입약관, 개인정보처리방침 이 사이트에 맞춰서 만들어죠”. Google 수정 완료는 사용자 보고로 기록하며, 이번 문서 작업에서 신규 가입 완료까지 재검증한 것으로 계산하지 않는다.

## 산출물

- `review.html`: 세 문서를 한 번에 읽고 인쇄할 수 있는 검토본. 외부 리소스·계정 연결 없음.
- `terms.ko.html`, `terms.ko.txt`: 회원가입 및 서비스 이용약관.
- `privacy.ko.html`, `privacy.ko.txt`: 개인정보처리방침.
- `signup-consent.ko.html`, `signup-consent.ko.txt`: 가입 시 필수 수집·이용 요약과 동의 표시.

HTML 조각과 TXT의 내용은 동일하다. `.txt`는 그누보드 가입약관 텍스트 입력에, HTML은 내용관리 페이지에 사용할 수 있도록 준비했다. 초안 표시와 대괄호 항목이 남은 파일을 운영 사이트로 복사하면 안 된다. 이 디렉터리는 배포 대상이 아니다.

## 게시 전에 확정할 정보

1. **사용자에게 필요한 정보:** 공개할 운영자의 법적 명칭, 개인정보 보호책임자 또는 실제 담당부서, 문의 이메일·전화번호. 실제 사용하는 정보만 기재하며 개인 계정 이메일을 임의로 공개하지 않는다. 유료 거래 제공 시 사업자 표시정보도 확인한다.
2. **소셜 제공 항목:** Google·Kakao 각각의 요청 권한, 프로필/전화번호 수신 여부와 실제 저장 필드. 불필요한 수집은 제거하거나 선택 처리한다. 생년월일·CI·주소·Google/Kakao 비밀번호를 확인 없이 수집 항목으로 넣지 않는다.
3. **보관·삭제:** 접속·보안/재생 이벤트/AI 응답/문의/백업별 기간과 실제 삭제 또는 분리보관 방식. 회원탈퇴 시 네이티브 회원정보뿐 아니라 소셜 매핑·목록·주문·AI 문서·파일까지 검증한다. 제안한 목적 달성 시 파기 원칙과 실제 동작을 일치시킨다.
4. **위탁·국외 이전:** 닷홈 계약상 법인명과 서버·백업 위치, 실제 AI·YouTube·결제 이용 여부, 계약 당사자, 전송 항목, 국가, 연락처, 보유기간과 법적 근거. `store:false`를 공급자 전체 로그 삭제 또는 무학습 보장으로 해석하지 않는다. 개인의 단순 API 토큰 입력이나 약관 전체 동의로 이 절차를 대체하지 않는다.
5. **연령·거래 정책:** 만 14세 이상 제안은 기존에 검증된 정책이 아니다. 선택하면 가입 전·서버 측 처리까지 맞춘다. 미성년 유료거래 동의, 취소/환급 접수와 처리, 개인정보 권리 행사 창구가 실제로 동작해야 한다.
6. **시행일:** 운영정보와 절차 확인 후 정한다. 작성일을 시행일로 소급 적용하지 않는다. 신규 문서 공지와 기존 회원에게 필요한 안내를 준비한다.

## 적용 위치와 일관성

- `provision` 내용관리 페이지: 이용약관 전문. PC/모바일 모두 동일한 확정본.
- `privacy` 내용관리 페이지: 개인정보처리방침 전문. 로그인 화면의 기존 링크 유지.
- 그누보드 설정 `cf_stipulation`: 같은 이용약관 TXT. 관련 `cf_privacy` 필드의 존재와 사용하는 화면은 운영 스키마 확인 후 같은 방침으로 맞춘다.
- 소셜 가입 PC/모바일의 `fregister_private`: 현재 고정된 기본 개인정보 표를 확정된 짧은 수집·이용 안내로 교체. 현재 표는 비밀번호 등 일반 가입 표현이 포함되어 전문만 수정해서는 불일치가 남는다.
- 기존 `agree`, `agree2` 필드명과 서버 검증을 보존한다. 별도 동의·연령 확인이 추가되면 서버에서도 확인하고 시행일·문서 버전·동의 시점 기록을 검증한다. 기존 회원에게 새 동의를 소급하여 만들어 넣지 않는다.
- 사전 백업, 제한된 변경 범위, 운영 최신 소스 확인과 롤백을 기존 배포 방식에 맞춰 준비한다. 이 초안 커밋에는 DB 변경·운영 배포·회원정보 변경이 없다.
