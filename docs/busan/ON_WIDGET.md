## 화면과 대화

`extend/busan-on.extend.php`의 native tail_sub 훅으로 우측 하단 ON 심볼, 순환 안내 말풍선, 대화창을 표시한다. Shadow DOM으로 기존 테마와 스타일을 분리한다. 모바일 safe-area, 작은 화면 너비, reduced motion을 지원한다. native 공통 tail을 생략하는 별도 페이지에는 별도 삽입이 필요하다.

widget-api.php는 native 회원 세션과 CSRF를 사용한다. 비회원은 이용 안내만, 승인 회원은 기존 검색 정책이 허용한 notice/LU_notice/note/LU_data 자료를 권한에 맞춰 검색한다. 비밀글, 인증 제한, 미승인 회원 자료는 제외한다. 대화는 브라우저 탭 세션에 최대20개 저장하며 서버에 별도 대화 기록을 수집하지 않는다. 현재 외부 AI API 미연결이므로 일반 생성형 자유 대화는 제공하지 않는다. persona.php에 향후 연결할 응대 지침을 함께 보관한다.

## 신규 글 보충 댓글

write_update_after 훅은 신규 글과 답글만 private metadata queue에 등록한다. 수정 글과 활동계정 본인 글은 제외한다. GitHub Actions busan-widget.yml의 약5분 스케줄에서 인증된 worker가 최대5건 처리한다. GitHub 스케줄 지연 가능. 기존 글 일괄 댓글 없음.

현재는 조직부장 안내가 없는 명시적인 지부장 결정·의견 요청에 한해 절차 안내 댓글을 남긴다. 일반 글, 중복 댓글, 비밀/민원/인증 제한 게시판은 생략한다. 외부 AI로 게시글을 보내지 않는다. 모든 주제에 대한 자동 분석·추가 자료 작성은 아직 구현하지 않았다.

댓글은 busanjibuon 회원의 native 인증을 검증한 뒤 기존 write_comment_update.php를 실행해 카운터, 캐시, 포인트, 훅을 유지한다. 별도 이메일 발송은 끈다. 활동계정 level10이며 기존 최고관리자 cf_admin은 유지한다.

private comments-settings.json enabled=false로 댓글 기능만 중지할 수 있다. 큐에는 게시판/글번호/시각/상태만 저장한다. 기존 글과 계정의 파일·내용을 삭제하지 않는다. 인증정보는 private activity-account.json에만 있고 로그·저장소에 출력하지 않는다.
