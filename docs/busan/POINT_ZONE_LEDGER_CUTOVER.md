# 부산지부 POINT ZONE — 원장 유지 / 영카트 호환 연동

**2026-11-25 사용자 정정: 기존 회원·포인트 시스템은 변경하지 않는다. 영카트만 기존 포인트 시스템에 맞춘다.**

이전 MyISAM→InnoDB 운영 원장 전환 계획은 철회. 운영 회원 테이블, 포인트 원장, 포인트 규칙, 그누보드 코어 및 저장 엔진 변경 금지. 이전 직접 SQL 원장 구현은 격리 실험 기록이며 운영에 배포하지 않는다.

## 현재 채택한 구조
- 영카트 가격·수량·재고는 영카트에서 관리한다.
- 기존 회원 잔액과 원장 합계 조회. 구매·취소 시 기존 `insert_point()` 호출. 취소는 원 결제 포인트만 반환하며 기존 양수 적립 정책을 그대로 따른다. 별도 운영 포인트 원장 없음.
- 주문번호와 고유 거래 종류로 기존 원장 내역을 확인한다. 영카트 요청 및 주문 영수증만 별도 기록한다.
- MyISAM은 원장과 영카트 사이의 단일 롤백을 제공하지 않는다. 영카트에서 주문 준비를 먼저 기록하고 기존 API 호출 뒤 결과 확인 후 완료한다. 실패·불확실 시 재호출하지 않고 확인 대기로 둔다. 기존 원장과 동시 호출의 위험은 실운영 검증 전 차단 조건이다.
- 공식 그누보드 5.6.4의 변경 없는 포인트 함수와 MyISAM 모형을 사용하여 격리 검증. 실제 운영 소스의 차이 및 기존 관리자/선물/AI 등 동시 호출 검증은 아직 미완료.
- 현재 코드는 격리 환경 전용이며 운영 주문 처리 경로 및 실제 판매는 미활성 상태.

## 남은 출시 검증
1. 공식 API와 설치된 기존 API 호환 확인, 실제 동시 차감/잔액 검증.
2. 영카트 측 확인 대기 주문의 관리자 대사·복구 처리, 권한 및 CSRF, 기존 현금 결제 경로 차단, 운영 UI 검수.
3. 상품은 사용자 기획 전 등록 금지. 운영 배포 전 백업 및 승인된 변경 범위 확인. 운영 원장 스키마·잔액 변경 없음.
