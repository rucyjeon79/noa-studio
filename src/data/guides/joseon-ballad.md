# 조선 발라드 — EP MUSIC PRODUCTION & CONTENT CREATION
OPTIMIZED MASTER GUIDELINE

입력은 EP 번호 + 원곡 제목 + 원곡 가사만.
목표는 단순 개사가 아니다. 현대 원곡을 조선 귀족 여성이 남긴 연모의 노래로 재해석한다.
음악·가사·이미지·제목·영상 콘텐츠가 하나의 세계관으로 연결된다.

## 1. 고정 장르
조선 발라드.
콘셉트: 조선의 여인이 마음에 품은 이를 향해, 말하지 못한 사랑과 한을 노래하다.
키워드: 연모, 그리움, 기다림, 절제된 사랑, 외로움, 한, 이별, 운명, 여운, 고요함.
철학: 말하지 못한 사랑을 노래로 대신 전하는 조선의 여인.

## 2–3. 입력 / EP 번호
장르를 따로 쓰지 않아도 조선 발라드를 적용한다.
EP 번호는 변경·번역·재배열·삭제·재생성 금지. 모든 콘텐츠에서 동일.

## 4. 작품명
원곡 제목을 그대로 쓰지 않는다. 제목·가사·감정·관계·계절·시간·장소·이별·그리움·조선 여성 관점을 분석한 뒤 한자말 작품명을 새로 만든다.
표기: 한글(한문). 예: 그리운 밤(懷夜).
단순 한자 번역 금지.
원제가 이미 한글(한문)이면 유지.
EP.01–30은 장부 고정. 확정 후 변경·재사용 금지.
속편: 여휘→재휘, 소생→답광, 심등→점등, 비상→화광, 조익→야익→완익.

## 5. 화자
모든 곡의 기본 화자 = 조선시대 귀족 여성. 1인칭.
양반가 규수 또는 귀부인. 품위·절제. 마음을 쉽게 말하지 못함. 기다림.
곡에 따라 미혼 규수 / 혼인 앞 / 기다림 / 이별 / 떠난 임을 그리는 여인으로 세부만 바꾼다.

## 6–9. 가사
현대인이 이해하면서 품격이 느껴지는 말. 그대/임/마음/연모/사무치다/기다리다/그립다/품다/머물다/닿다/보내다.
하옵니다 등은 필요 시에만. 모든 문장을 사극체로 만들지 말 것. 감정 전달이 우선.
원곡 → 핵심 감정 → 이야기 → 조선 상황 재해석 → 1인칭 → 시대 표현 → 시적 재창작.
직역·원문 유지·현대 연애 말 남발·의미 없는 고어체 금지.
실제 가사는 한국어만. 영어/일본어/중국어/외국어 훅·랩·애드립 금지. Suno 연출만 영어.
직설과 시적 이미지(달빛·별·바람·꽃·비·눈·강·연못·대숲·창호·등불·처마·옷자락·편지·새벽·밤)를 균형.

## 10–11. 구조 / 후렴
[Intro] [Verse 1] [Pre-Chorus] [Chorus] [Verse 2] [Pre-Chorus 2] [Chorus 2] [Bridge] [Final Chorus] [Outro]
필요 시 Instrumental / Interlude / Break. 감정 흐름 우선.
후렴은 짧고 기억되며 반복할수록 깊어진다. 같은 문장 과잉 반복 금지.

## 12–13. 보컬
Female Vocal 고정. 깊고 따뜻한 음색, 애절, 한, 섬세한 호흡, 시김새, 절제, 여운.
한이 섞인 창: 농음, 꺾는 음, 미세한 떨림, 여린 시작, 클라이맥스 울림.
판소리 재현 아님. 남성 리드 금지.

## 14–19. 편곡
전통악기 중심: 가야금(서정), 해금(한), 대금(공간), 거문고(낮은 정서), 아쟁(클라이맥스), 장구·북(절제된 전환).
한 곡에 전 악기 쓰지 말 것. 적게 쓰고 깊게.
현대 보조만: soft bass, sub, minimal kick, soft percussion, ambient pad. 전통을 압도 금지.
금지: EDM, 클럽 비트, 과한 힙합 드럼, 강한 신스.
여백. Intro 전통 도입 → Verse 최소 → Pre 확장 → Chorus 핵심 악기 → Bridge 내면 → Final 정점 → Outro 덜어냄.
BPM 고정 아님. 65–100. 느린 연모 65–75, 일반 75–90, 리듬 90–100. 여백·호흡이 BPM보다 우선.
Intro 5–10초에 조선의 밤과 여인의 마음. 3–4분. 단순 반복으로 길이 늘리지 말 것.

## 20–21. 가사 포맷
모든 섹션에 보컬 표기 + 영어 연출 지시. 실제 가사는 한국어만.
예:
[Verse 1] [Female Vocal]
(Delicate Korean female vocal with restrained han-inspired ornamentation, sparse gayageum and haegeum, spacious pauses.)
달빛이 창호에 머물고
그대 생각에 밤이 깊어갑니다
연출은 Vocal / technique / Emotion / Rhythm / Instrument / Space / Dynamics / Transition을 담는다. Soft vocal 한 줄 금지.

## 22. SUNO STYLE
영어, 1000자 이내.
방향: Cinematic Korean Joseon ballad, traditional Korean instrumentation, emotional female vocal, restrained han, elegant longing, poetic melancholy, minimal arrangement, spacious cinematic atmosphere.
필수: Female Korean Vocal, traditional ornaments, han-inspired, gayageum/haegeum/daegeum/geomungo/ajaeng, minimal, spacious, cinematic.
필요 시에만 soft bass / minimal kick / ambient.
금지: male lead, foreign-language lyrics, EDM, K-pop production, 과한 전자음, 전통을 압도하는 bass.

## 23–29. 썸네일
16:9 / 8K / Premium / Cinematic / Photorealistic.
모든 EP에 조선 귀족 여성 필수. 곡마다 나이·의상·헤어·장신구·표정·자세·시선·계절·시간·장소·조명·앵글·위치를 새로.
배경과 인물이 하나의 이야기. 예시 반복 금지. 가사에서 새 장면을 만든다.
텍스트 4개만: 좌상단 EP.{번호} / 중앙 한글(한문) 작품명(가장 큼) / 아래 감성 한줄 / 아래 조선 발라드.
얼굴(눈·코·입·윤곽) 위 텍스트 금지. 충돌하면 인물을 옮긴다.
서체: classical/elegant/editorial serif. 가독성 떨어지는 붓글씨 금지.
Gemini는 영어. 로고·워터마크·아티스트명·앨범명·해시태그·추가 문구 금지.

## 30. 플레이리스트 썸네일
세계관 대표. 개별 곡 장면 아님. EP 번호·트랙리스트를 이미지에 넣지 않음.
확정 배치: 좌상단 Act.N / 중앙 Playlist EP.x~EP.y / 아래 해당 Act 감성 / 아래 조선 발라드.

## 31–34. 유튜브
감성 한줄: 한국어, 한 문장, 시적, 장면이 보임. 장르 설명 문장 금지.
제목: 사용자 설정 형식이 0순위. 기본 골격에 EP 번호·작품명·감성·조선 발라드. 100자 이내.
설명란: 여인의 이야기 해설. 연모·말하지 못한 마음·전통악기·여성 보컬. 장르 나열 금지.
태그 예: #조선발라드 #국악발라드 #한국전통음악 #사극감성 #연모 #그리움 #여성보컬 #감성발라드 — 곡마다 맞게.

## 35. 앱 출력 순서 (화면)
요약 → 확정 제목 → 가사 → SUNO STYLE → Gemini 썸네일 → YouTube 제목 → 설명란.
지침서 §35의 내부 작업 순서는 지키되, 화면 블록 순서는 이 앱 순서를 따른다.

## 36–38. 워크플로 / 절대 규칙
EP 확인 → 원곡 분석 → 감정·이야기 → 조선 재해석 → 1인칭 → 작품명 확정(장부 우선) → 감성 한줄 → 가사 재창작 → Suno → 시각 이야기 → Gemini → YouTube.
① 장르 고정 ② 입력 3종 ③ EP 번호 불변 ④ 핵심 의미·감정 유지 ⑤ 제목 단순번역 금지 ⑥ 한글(한문) ⑦ 원제가 한글(한문)이면 유지 ⑧ 장부 재사용 금지 ⑨ 1인칭 귀족 여성 ⑩ 한국어만 ⑪ 여성 보컬 ⑫ 한이 섞인 창 ⑬ 전통악기 중심 ⑭ 현대는 보조 ⑮ 섹션마다 보컬+영어연출 ⑯ Suno ≤1000 ⑰ 썸네일 귀족 여성·시대 의상 ⑱ 얼굴 보호 ⑲ 불필요 텍스트 금지.

## 39. 장부 (EP.01–30)
코드의 joseon-ledger와 동일. 재사용 금지. 마지막 페이지 EP.30 화성(化星) / Act.3.

## 40. Act 플레이리스트
개별 EP 7단이 아니라 묶음 페이지.
① 요약 ② 수록곡 ③ Gemini ④ YouTube 제목 ⑤ 설명 ⑥ 묶음 한 줄.
확정 Act 감성:
Act.1 말하지 못한 연모가 달빛처럼 깊어지는 밤
Act.2 혼자 남은 사랑을 건너, 하늘을 향해 일어서는 밤
Act.3 불꽃을 지나, 별이 되어 하늘에 남는 밤
제목 예:
