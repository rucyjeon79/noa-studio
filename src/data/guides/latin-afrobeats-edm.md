# Latin Afrobeats EDM K-POP Rebirth

한국어 원곡 서사를 유지하며 Latin + Afrobeats + EDM으로 밝은 K-POP 댄스곡으로 재탄생.
Minor보다 Major. Night보다 Neon / Festival / Summer.

핵심: 라틴·아프로 리듬 + EDM bass intro, 베이스 강조, 전자 손타악(짧고 탄력), 한국어+영어 Hook, 밝고 귀여운 여성 보컬, Dance Break, 3분 이상.

입력: EP 번호 + 원곡 제목 + 원곡 가사. ACT 표기 금지. 원제 유지. [LKE]는 내부 표기일 뿐 유튜브/썸네일 제목에 넣지 않음.

## 서사
사건 순서·메시지·핵심 상징·감정 흐름 유지.
허용: 톤을 경쾌하게, 한/영 훅, Chorus 반복, Dance Break 확장.

## 가사 톤
금지: 고독, 절망, 어두운 밤 반복, 비/눈/찬바람 중심, 과도한 철학, 침울, 느린 발라드.
허용: 설렘, 즐거움, 그리움, 희망, 두근거림, 밝은 로맨스, 경쾌한 기다림.
한국어 몸통 + Chorus 영어 Hook 1–2줄. 반복은 가사에 직접.

## 보컬 / 사운드
밝고 귀여운 여성. 리듬 발음, 짧은 호흡.
Intro: deep sub bass riff + punchy kick + minimal beat → afro/latin percussion.
EDM synth lead, arpeggio, risers, impact, electronic dance beat. 114–118 BPM.

## 구조
[Intro] 즉시 bass drop, no long buildup. 선택: Whispered Narration 영어 1–2줄.
[Groove Build] hand perc + afro + latin + arpeggio
[Verse 1] afro/latin groove, female vocal
[Pre-Chorus] synth tension, clap, bass rising
[Chorus] festival drop, bright lead, English Hook
[Verse 2] 리프 변주
[Pre-Drop] riser, arpeggio, bass build
[Chorus]
[Dance Break] 보컬 없는 연주
[Energy Build]
[Final Chorus] 가장 큰 드롭, female harmony
[Outro] fade
태그 [ ], 연출 ( ), 가사 문장.

## Suno
저장 베이스를 쓰고 곡 감정만 보정. 영어 1000자 이하. 114–118 BPM. Major, festival, cute female, English hook.
