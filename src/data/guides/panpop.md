# PANPOP : The New Korean Pop
Korean Pansori Meets K-Pop

판소리를 그대로 재현하지 않는다. 판소리의 보컬 표현·시김새·호흡·서사 말맛을 현대 K-pop과 결합한 새 한국형 K-pop.
브랜드명 PANPOP은 유튜브/썸네일에 쓰고, Suno에서는 그 단어에 의존하지 말고 음악적 특징을 구체적으로 쓴다.

CORE: Trendy Modern K-pop / Korean Pansori Female Vocal / Powerful Emotional Vocal / Bass Only / Minimal / Cinematic / Catchy Vocal Hook / Bass Drop / Modern Korean Identity.

입력: EP 번호 + 제목 + 가사. 장르·보컬은 고정(Female Korean Pansori Vocal, Bass Only).

워크플로: STORY → EMOTION → LYRICS → TITLE → ENGLISH HOOK → CHORUS → BASS DROP → MUSIC → THUMBNAIL → YOUTUBE → DESCRIPTION.
원곡 스토리·감정을 먼저. 장르를 억지로 넣지 말 것.
시적이지만 어렵지 않게 / 세련됐지만 감정은 분명하게 / 짧지만 기억에 남게 / 강렬하지만 과하지 않게 / 전통적이지만 낡지 않게.

## 스토리
주인공·상대·관계·상황·시간·장소·계절·날씨·사건·장면·핵심/보조 감정·메시지·가장 시각적인 장면·판소리 어투가 살 지점을 파악.
CORE SCENE 하나 = 가사·후렴·음악·썸네일·제목·설명의 중심.

## 제목
원제 유지. 짧음·감정·PANPOP 감각·발음 리듬·훅 가능성 실패 시에만 개선. 장르명을 제목에 반복하지 말 것.

## 가사
스토리·감정 유지. 긴 문장 압축. 현대 K-pop + 판소리 말맛.
어허/에헤야/아이고/좋다/가거라/오너라/보아라/들어라 등은 자연스러울 때만.
금지: 전체 고어체, 추임새 과잉, 판소리 대본화, 어려운 한자 남발.
목표: 현대 K-pop인데 판소리의 말맛이 느껴지는 가사.
짧은 영어 Signature Hook. TITLE → ENGLISH HOOK → CHORUS → BASS DROP.
명사는 핵심만 영어, 조사는 한글. 과잉 영어 금지.
Chorus는 짧고 반복·리듬·제목/훅 연결. 한 번에 기억.

## Bass Drop
일반 EDM 드롭 아님. BASS DROP + PANSORI VOCAL DROP.
VOCAL → SPACE → BASS DROP → VOCAL HOOK.
드롭 직전 베이스 최소 → 공간 → 긴장 → 베이스 재진입 → 짧은 훅 반복.
보컬이 중심. 베이스가 보컬을 압도하지 않음.

## Bass Only
허용: Bass만.
금지: drums, percussion, kick, snare, hat, cymbals, claps, shakers, piano, e-piano, keys, guitar, synth, pad, strings, orchestra, brass, woodwinds, organ, harp, 장구/북/가야금/해금/대금/사물놀이/모든 국악·멜로디·리듬·하모니·드럼 사운드.
Bass 역할: groove, pulse, rhythm, tension, movement, minimal harmony, drop energy. 복잡하게 만들지 말 것.
대비: Female Pansori Vocal + Bass.

## 보컬
Female Korean Pansori Vocal. Strong projection, breath, sigimsae, bends, dramatic phrasing.
전통 판소리 복제 아님. VOCALS ARE THE ABSOLUTE FIRST PRIORITY.

템포는 감정에 따라 slow / slow-mid / mid. 무조건 빠른 댄스팝 금지.
