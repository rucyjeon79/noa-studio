# NOA STUDIO 2.0 PC preview

Deploy the standalone `index.html` in this directory to `/hosting/noastudio/html/preview/index.html` using Dothome FTP or its file manager.

Do not replace `/hosting/noastudio/html/index.php`, `common.php`, `.htaccess`, or existing GnuBoard files.

The preview is UI-only; no music streaming, Grok integration, or database writes are enabled. Verify `https://noastudio.ai.kr/preview/` after upload.
